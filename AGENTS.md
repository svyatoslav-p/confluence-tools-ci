# Confluence Tools CI

Расширение Chrome Manifest V3 для Confluence Data Center 9.2.2.
Стек: TypeScript, WXT, DOM/CSS без UI-фреймворка. Интерфейс русский.
Серверный плагин устанавливать нельзя.

## Команды

- `npm ci` — установка зависимостей по lock-файлу.
- `npm run compile` — проверка типов.
- `npm test` — регрессионные тесты ядра и панели.
- `npm run test:bundle` — сборка и проверка разделения кода между контекстами.
- `npm run build` — сборка в `.output/chrome-mv3`.
- `npm run zip` — архив для ручной установки.
- `npm run icons` — генерация PNG из `assets/icon.svg`.
- `npm run dev` — режим разработки WXT.

После изменений выполняйте проверку типов и сборку. Не выдавайте успешную сборку
за проверку поведения в браузере: в отчёте укажите, что реально проверено.
Сохраняйте локальную сборку и ручное обновление через chrome://extensions.
Для распакованной установки доступно обновление полного ZIP из официального GitHub
Releases по действию пользователя. После установки пользователь перезагружает Confluence.

## Архитектура

- `entrypoints/background.ts` — регистрация скриптов на разрешённых хостах,
  открытие страницы настроек.
- `entrypoints/bridge.ts` — изолированный скрипт с доступом к API расширения.
- `entrypoints/app.ts`, `core/app.ts` — приложение в контексте Confluence,
  где доступен TinyMCE; настройки приходят через мост сообщений.
- `entrypoints/options/` — страница настроек.
- `entrypoints/popup/` — общий переключатель работы, блок «Модули» из описаний и открытие настроек.
- `core/` — типы, реестр модулей, настройки, сообщения, темы, горячие клавиши.
- `features/<имя>/definition.ts` — название и настройки модуля, только данные.
- `features/<имя>/index.ts` — реализация модуля в контексте страницы.
- `features/<имя>/README.md` — использование, настройки и устройство модуля; поддерживайте при изменении поведения.
- `core/definitions.ts` и `core/registry.ts` автоматически обнаруживают описания и реализации соответственно.
- `assets/`, `public/icon/`, `scripts/make-icons.mjs` — исходник и сборка иконки.

Описание экспортирует объект `FeatureDefinition` из `core/types.ts` и не импортирует
реализацию. Реализация экспортирует `Feature`, дополняя описание действиями и `setupEditor`.
Options, storage и bridge используют только описания. Background читает `hosts` и
глобальную настройку автоматической проверки без загрузки реализаций модулей.
На верхнем уровне файлов не обращайтесь к странице: инициализацию выполняйте при запуске.
Обработчики и элементы редактора убирайте функцией очистки из `setupEditor`.
Каркас перезапускает только модуль с изменёнными настройками; смена редактора пересоздаёт все.
`startApp()` возвращает единую функцию очистки; при удалении хоста UI приостанавливается,
но мост остаётся доступным для повторного включения. Не нарушайте back/forward cache.
Цвета UI берите из `--ct-*` в `core/theme.ts`, чтобы следовать теме Confluence.
Новые функции не должны требовать правки других модулей.

Проверка обновлений в `core/updates.ts` обращается к GitHub Releases официального
репозитория. Сравнивайте числовую версию тега последнего стабильного выпуска с
`chrome.runtime.getManifest().version`. У выпуска должен быть ZIP для Chrome с SHA-256.
WXT берёт локальную версию из `package.json`. На вкладке «Обновление» всегда видны
установленная версия и ссылка «Открыть сборки». После разрешения доступа к `api.github.com`
автоматическая проверка по умолчанию выполняется при запуске браузера и установке
расширения. При выключенном `autoCheckUpdates` запрос выполняется только по кнопке
«Проверить обновление». Доступное обновление обозначается отметкой «!» и статусом.
Перед установкой ZIP сверяйте версию, SHA-256 и путь установленного расширения.

## Согласованное поведение

Модуль `spoilers` работает только при просмотре: управляет стандартными Expand и
сворачиваемыми Code Block одним пунктом «Развернуть/Свернуть спойлеры». Типы выбираются
в настройках (оба по умолчанию включены); только выбранные типы влияют на команду.
Если есть закрытые, раскрывает все выбранные, иначе сворачивает их. Использует штатные
кнопки Expand с `aria-expanded` и `.collapse-source` с состоянием иконки Code Block только внутри
`#main-content`. Открывайте
родителей раньше детей, закрывайте в обратном порядке; уже заданное состояние не
переключайте. Не сохраняйте страницу и не затрагивайте интерфейс вне её содержимого.

Нажатие на значок Chrome открывает popup. Общая пауза хранится в `Settings.enabled`
(по умолчанию true), убирает UI страницы и останавливает модули, сохраняя их включение
и значения настроек. Мост остаётся доступным для возобновления без перезагрузки.
Проверка обновлений продолжает работать. Popup и options используют одно хранилище
и синхронизируют переключатели модулей; popup импортирует только описания.

Модуль `change-history` доступен только при просмотре опубликованной дочерней страницы.
Он переносит четыре ячейки строки таблицы «Задачи» в таблицу «История» непосредственного
родителя и добавляет ссылку в пятую колонку «Версия». Повторный запуск обновляет запись,
строки сортируются по возрастанию числовых частей версии. Неизменившиеся данные
и порядок не создают новую версию. Строки без номера идут в конце в исходном порядке.
Не затрагивайте остальную разметку.
Заголовок раздела и пять названий колонок таблицы родителя задаются в настройках
модуля. Пустой заголовок отключает его проверку, названия колонок обязательны;
регистр и лишние пробелы не учитываются. Порядок и назначение колонок фиксированы.
Проверяйте структуру таблиц, HTTP-ошибки и конфликты версий; не перезаписывайте их автоматически.
Необязательное `MenuAction.description` открывается отдельной кнопкой ⓘ в ядре меню.

Панель форматирования содержит очистку стиля (Tx), стиль по умолчанию (A↺),
«Удалено» (красный − с зачёркиванием текста), «Добавлено» (зелёный +) и меню «…».
В меню входят «Устарело» и обратимое преобразование одного имени camelCase ↔ snake_case.
Также в меню есть Upper/Lower для смены регистра выделенного текста с сохранением разметки.
После выполнения любого действия панель скрывается до нового выделения или повторного Ctrl.
Пункт преобразования называется Camel/Snake. В меню используются текстовые подписи без иконок.
Горячие клавиши по умолчанию не назначены; привязка к физической клавише
должна работать и в русской раскладке. Цвета по умолчанию #C9372C, #1F845A,
#946F00 записываются через соответствующие переменные палитры Confluence.

Видимость каждой кнопки настраивается отдельно, скрытие не отключает горячую клавишу.
Кнопка «Очистить стиль» по умолчанию скрыта.
Панель появляется по Ctrl либо, по умолчанию, после отпускания левой
кнопки мыши при выделении. Положение — у конца выделения. Не окрашивайте
невыделенные вложенные пункты списка через наследование стилей от li.
Пункты форматирования в плавающем меню не нужны; на плавающей кнопке волшебная палочка.
Настройки клавиш объединены в блок, общий сброс возвращает настройки модуля к умолчаниям.

## Скилы Codex

Проектные скилы находятся в `.agents/skills/`:

- `find-skills` — поиск и установка дополнительных скилов.
- `code-review-and-quality` — ревью правильности, простоты, архитектуры,
  безопасности и производительности.
- `typescript-best-practices` — рекомендации по TypeScript.

Перед применением читайте соответствующий `SKILL.md`. Ссылки скилов на другие,
неустановленные скилы не являются основанием для автоматического добавления
зависимостей или усложнения архитектуры. Приоритет имеют задача пользователя
и существующий стек.

## Проверка и git

Тестовый стенд: http://confluence.ideveloplab.ru:8095/.
Данные на нём тестовые. Учётные данные берите только из предоставленного пользователем
контекста или локальных заметок и не публикуйте их. Установка расширения в Chrome
и выполнение кода в странице — разные способы проверки; явно указывайте способ.

Не меняйте сторонний образец, не добавляйте зависимости без необходимости.
Не коммитьте `node_modules/`, `.output/`, `.wxt/`, секреты или пароли.
Коммиты и отправку в удалённый репозиторий выполняйте по просьбе пользователя.
Заголовки и описания коммитов пишите на английском языке.
