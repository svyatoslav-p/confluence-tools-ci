Адреса сервисов

Расширение работает только на перечисленных адресах. Для каждого адреса Chrome один раз попросит разрешение.

    Модули

    Обновление

    При запуске браузера версия расширения сравнивается с version в package.json. При доступном обновлении на значке появляется «!», а здесь — ссылка на сборки. Пустой адрес отключает проверку.

    Для проверки обновлений разрешите доступ к . Расширение читает с этого сайта package.json, чтобы узнать номер доступной версии.

    Текущая версия:

    Изменения сохраняются сразу. Открытые страницы Confluence подхватывают их без перезагрузки; после добавления адреса страницу нужно обновить.
