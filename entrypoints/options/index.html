Адреса сервисов

Расширение работает только на перечисленных адресах. Для каждого адреса Chrome один раз попросит разрешение.

    Модули

    Обновление

    Расширение ищет готовый выпуск в GitHub Releases. Когда доступно обновление, на значке появляется «!».

    Для проверки обновлений разрешите доступ к api.github.com. Расширение читает номер выпуска и данные о ZIP для Chrome.

    Текущая версия:

    Открыть сборки

    Установка скачает ZIP из официального выпуска на GitHub. Chrome может попросить выбрать папку расширения и разрешить запись.

    Изменения сохраняются сразу. Открытые страницы Confluence подхватывают их без перезагрузки; после добавления адреса страницу нужно обновить.
