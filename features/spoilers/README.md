# Спойлеры

Модуль управляет обычными макросами Expand и сворачиваемыми блоками Code Block в содержимом текущей страницы
Confluence Data Center 9.2.2, включая вложенные. Доступен в режиме просмотра.

Откройте меню плавающей кнопки с волшебной палочкой и выберите
**Развернуть/Свернуть спойлеры**. Пункт показывается без заголовка категории.

- Если хотя бы один спойлер выбранных типов закрыт, команда разворачивает все выбранные блоки.
- Если все выбранные спойлеры открыты, команда сворачивает их все.

Повторный вызов переключает общее состояние. Состояние отдельных спойлеров
по-прежнему можно менять штатными кнопками Confluence. Изменения относятся только
к текущему просмотру: содержимое страницы не сохраняется и REST API не вызывается.

Модуль включается и выключается в блоке «Модули» окна расширения Chrome либо на
вкладке «Модули» полной страницы настроек.

## Настройки

В группе **«Типы спойлеров»** можно независимо выбрать:

- **Обычные спойлеры (Expand)** — раскрывающиеся разделы текста, включая вложенные.
- **Блоки кода (Code Block)** — исходный код с командой «Развернуть исходный код»,
  например JSON в разделе «Пример ответа».

Оба типа включены по умолчанию. Отключённые типы не переключаются и не влияют на выбор
общего действия. Если оба флажка сняты, команда предлагает выбрать типы в настройках.
Кнопка «По умолчанию» снова включает оба типа.

## Реализация

- `definition.ts` — описание модуля для настроек и окна расширения.
- `index.ts` — общая команда меню и обработка штатных элементов управления обоих типов внутри `#main-content`.

Разворачивание идёт от родителей к вложенным блокам, сворачивание — в обратном
порядке. Уже установленные состояния не переключаются. После обработки проверяется
результат; если часть блоков не переключилась, показывается сообщение об ошибке.
При большом количестве блоков выполнение уступает браузеру каждые 20 спойлеров.
Обычные несворачиваемые блоки кода и ещё не инициализированные макросы пропускаются.
Блоки сторонних плагинов, содержимое iframe и элементы вне основного текста страницы
не обрабатываются.

Регрессионные тесты: `tests/spoilers.test.mjs`. Общие команды сборки и проверки
описаны в основном [README](../../README.md#проверка-кода).
