# Создать новую версию

Откройте родительскую страницу спецификации в режиме просмотра и выберите
**«Создать новую версию»** в плавающем меню Confluence Tools CI.

1. Модуль находит непосредственную дочернюю страницу с наибольшим номером `[vX.X]`, учитывая также страницы с префиксом `draft `. Из `[v2.2] Получение алертов.API.ОСП` получится `draft [v2.3] Получение алертов.API.ОСП`.
2. Введите ключ задачи Jira для SA Task, затем для Story. Например PLAT-1234. Пустой ввод оставляет ячейку пустой. «Отмена» прерывает операцию.
3. Расширение создаёт дочернюю страницу и переносит вложения. В таблице «Задачи» ключи становятся макросами Jira, «Ответственный аналитик» заполняется упоминанием текущего пользователя, а «Описание» очищается.
4. Сообщение об успехе показывает название исходной страницы. Затем открывается новая версия.

Макрос Jira использует параметры подключения из исходной ячейки. Если в ней их нет, модуль берёт их из второй ячейки с задачей. Если обе ячейки пусты или содержат обычный текст, макрос сохраняется с ключом задачи и использует интеграцию Confluence по умолчанию. Для отображения задачи нужна настроенная интеграция Jira в Confluence.

`draft ` — префикс названия. Видимость новой страницы определяется её расположением в Confluence. Если на исходной странице задано собственное ограничение просмотра, модуль останавливается перед созданием копии. Если перенос файла прервётся после создания страницы, сообщение укажет страницу и проблемное вложение.

Модуль можно выключить в настройках или в окне расширения Chrome.
