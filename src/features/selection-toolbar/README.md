# Панель быстрого форматирования

В редакторе выделите текст и отпустите левую кнопку мыши. На панели появятся
«Применить правки» (A✓), «Удалено» (красный −), «Добавлено» (зелёный +) и «…».
Горячие клавиши по умолчанию не назначены.
Наведите указатель на «…» или нажмите эту кнопку, чтобы открыть меню со «Стилем по умолчанию»,
«Устарело», «Camel/Snake» и «Upper/Lower». При нехватке места справа меню раскрывается слева.
Выделите целое имя, например `oper_plan_draft_id`:
команда Camel/Snake заменит его на `operPlanDraftId`, повторный вызов вернёт исходное написание.
Upper/Lower переключает регистр всего выделенного текста. Если есть строчные
буквы, текст становится заглавным; иначе — строчным. Оформление и адреса ссылок сохраняются.
После выполнения команды панель скрывается. Новое выделение или повторное нажатие Ctrl
в режиме показа по Ctrl открывает её снова.
Видимость этих команд задаётся в группе «Дополнительное меню (…)». Для преобразования
можно назначить горячую клавишу; по умолчанию она свободна.
Пункт **«Стиль по умолчанию»** возвращает обычный цвет текста, убирает
зачёркивание и возвращает ссылкам стандартный синий цвет, сохраняя их адреса.
Она применяется к выделению.
Кнопка **A✓ «Применить правки»** удаляет из выделения красный зачёркнутый текст и
применяет «Стиль по умолчанию» к оставшемуся тексту. Распознаётся стандартный красный
и цвет «Удалено» из настроек. Пустые после удаления пункты списка исчезают. Если во
вложенном списке остались пункты, они сохраняются вместе с родительским пунктом.
В ячейках таблицы опустевшая после удаления строка исчезает вместе с переносом.
При выделении нескольких ячеек команда обрабатывает каждую выделенную ячейку.
Кнопка **+ «Добавлено»** окрашивает выделенный текст и сохраняет исходный цвет ссылок внутри выделения.
По умолчанию панель появляется без Ctrl после отпускания кнопки мыши.
В настройках можно включить режим по Ctrl, выбрать видимые кнопки и изменить
горячие клавиши. Скрытые кнопки сохраняют горячие клавиши; если скрыть все,
панель не появляется. Сохранённые настройки показа без Ctrl не перезаписываются;
кнопка «По умолчанию» применяет новые значения по умолчанию.

## Настройки

Модуль включается и выключается на вкладке «Модули». Там же задаются режим появления,
цвета «Добавлено», «Удалено», «Устарело», видимость каждой кнопки и горячие клавиши.
Все сочетания по умолчанию свободны. Сочетания привязаны к физическим клавишам и работают
при русской раскладке. Кнопка «По умолчанию» сбрасывает все настройки панели.
Светлая или тёмная тема выбирается автоматически по теме Confluence.

## Реализация

- `definition.ts` — описание модуля, настройки и их значения по умолчанию.
- `index.ts` — UI панели, выделение, команды TinyMCE и преобразования текста.
- `deleted-text.ts` — удаление зачёркнутого красного текста и опустевших пунктов списка.
- `identifier.ts` — проверка имени и обратимое преобразование Camel/Snake.
- `text-selection.ts` — работа с текстовыми узлами выделения, сохранение оформления при смене регистра.

Модуль работает в редакторе TinyMCE, сохраняет разметку и ссылки при преобразовании
текста. При отключении удаляет UI и обработчики событий.

Регрессионные проверки находятся в `tests/toolbar.test.mjs` и `tests/text-case.test.mjs`.
Общие команды проверки описаны в основном [README](../../../README.md#проверка-и-тесты).
